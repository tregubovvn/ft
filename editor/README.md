# Formula Test Editor

https://tregubovvn.github.io/ft/editor/index.html

## Промпт для создания заданий
https://gist.github.com/tregubovvn/e32e6561ac50b1866e5cb9de2a238f68

**Formula Test Editor** — одностраничное веб-приложение для создания и редактирования XML-тестов по проверке знаний формул, предназначенное для работы в паре с приложением [Formula Builder](https://tregubovvn.github.io/ft/index.html). Редактор предоставляет удобный графический интерфейс для работы с формулами (LaTeX) и условными обозначениями, живой предпросмотр, интеграцию с GitHub Gist для хранения данных и DeepSeek AI для генерации контента.

Приложение реализовано в виде одного HTML-файла, не требует установки серверного ПО и работает в любом современном браузере.

---

## Особенности

- **Чистый интерфейс**: Современный тёмный дизайн без лишних визуальных шумов.
- **Двусторонняя синхронизация**: Изменения в форме мгновенно отражаются в XML, а ручное редактирование XML применяется к форме кнопкой «Применить изменения».
- **Живой предпросмотр**: Формула рендерится через KaTeX прямо в процессе набора LaTeX-кода.
- **Точное превью фрагментов**: Формула разбивается на фрагменты тем же алгоритмом, что и в тестирующем приложении — вы всегда видите, какие куски формулы получит студент и в каком порядке они образуют правильный ответ.
- **Валидация**: Автоматическая проверка формул на типичные проблемы (ошибки LaTeX, дубликаты фрагментов, слишком простое разбиение).
- **Работа с API**: Встроенная поддержка GitHub Gist для сохранения/загрузки и DeepSeek для AI-ассистенции.
- **Полная автономность**: Приложение написано на чистом HTML/CSS/JS, не требует сборщиков и серверной части. Достаточно открыть файл в браузере.

## Функциональность

### 1. Редактор формул
Основная рабочая область приложения разбита на логические блоки:

- **Навигация**: Переключение между формулами теста с помощью вкладок или кнопок «Пред./След.». Возможность добавлять новые формулы и удалять существующие (с подтверждением). На вкладках с проблемными формулами отображается жёлтая точка-предупреждение.
- **Название формулы**: Отображается студенту вместо самой формулы — по нему он должен вспомнить и собрать формулу.
- **LaTeX**: Многострочное поле для ввода формулы в формате LaTeX с моноширинным шрифтом.
- **Предпросмотр**: Живой рендеринг формулы через KaTeX с сообщением об ошибке при некорректном синтаксисе.

### 2. Превью фрагментов и статус
Для каждой формулы редактор показывает:

- **Фрагменты сборки**: Результат разбиения LaTeX на фрагменты (с учётом `\frac`, `\sqrt`, степеней `^`, индексов `_`, скобок `\left...\right`) — пронумерованные блоки в правильном порядке. Порядок фрагментов и есть правильный ответ теста.
- **Статус готовности**:
  - ✓ Формула готова к тесту;
  - предупреждения: не задано название, пустой LaTeX, ошибка KaTeX, менее 2 фрагментов, есть одинаковые фрагменты (порядок сборки может быть неоднозначным).

### 3. Условные обозначения
Для каждой формулы можно задать список пар «символ — расшифровка»:

- Символ вводится в LaTeX-нотации (например, `E_k`) и рендерится рядом с полем.
- Обозначения показываются студенту как подсказка перед сборкой формулы.
- Добавление и удаление обозначений — одной кнопкой.

### 4. XML-панель
Нижняя часть экрана содержит код генерируемого XML.

- **Синхронизация**: XML обновляется в реальном времени при редактировании формы.
- **Применить изменения**: Кнопка парсинга вручную внесённых изменений в XML-код и применения их к визуальному редактору.
- **Копирование**: Быстрое копирование XML в буфер обмена.
- **Загрузить файл**: Загрузка XML с локального диска. Если указан GitHub Token — сразу создаётся новый GIST с этим содержимым.
- **Скачать**: Сохранение XML как локального файла (удобно для публикации на Яндекс.Диске).
- **Изменение размера**: Границу между редактором и XML-панелью можно перетаскивать мышью.

### 5. Интеграция с GitHub Gist
Приложение использует GitHub Gist как облачное хранилище для XML-файлов.

- **Новый GIST**: Создаёт новый Gist с текущим содержимым XML-панели.
- **Автосохранение**: После создания Gist все изменения (в форме или в XML) автоматически сохраняются через 1,5 секунды после последнего действия. Статус сохранения отображается в нижней строке состояния.
- **Ссылка на GIST**: После сохранения в шапке появляется прямая ссылка на Gist с кнопкой копирования.
- **Загрузить GIST**: Загрузка теста по полной ссылке, raw-ссылке или просто по ID Gist.
- **Открыть задание**: Открывает тестирующее приложение Formula Builder с загруженным файлом (`index.html?file=<raw_url>`) и копирует ссылку на задание в буфер обмена — можно сразу отправить студентам.

### 6. Интеграция с DeepSeek AI
Функция «Спросить DeepSeek» позволяет отправить содержимое XML-панели в нейросеть DeepSeek.

- **Workflow**: Вы заполняете XML текстом или инструкциями (например, «Сгенерируй 5 формул по кинематике с условными обозначениями...»), нажимаете кнопку, и AI возвращает результат прямо в XML-панель.
- **Гибкость**: Вы можете использовать промпты прямо в тексте XML, так как модель принимает всё содержимое поля как контекст.

## Настройка и установка

### Шаг 1: Получение токенов

Для работы функций сохранения и AI вам понадобятся API-ключи.

**GitHub Token (Fine-grained Personal Access Token):**
1. Перейдите в [настройки токенов GitHub](https://github.com/settings/tokens?type=beta).
2. Нажмите **Generate new token (fine-grained)**.
3. Укажите имя токена и срок действия.
4. В разделе **Repository access** выберите "Only select repositories" (если хотите ограничить) или "All repositories".
5. В разделе **Permissions -> Account permissions** найдите **Gists** и установите **Read and write**.
6. Сгенерируйте токен и скопируйте его.

**DeepSeek Token:**
1. Зарегистрируйтесь или войдите на [platform.deepseek.com](https://platform.deepseek.com/).
2. Перейдите в раздел [API Keys](https://platform.deepseek.com/api_keys).
3. Создайте новый ключ и скопируйте его.

### Шаг 2: Запуск

1. Скачайте `formula_editor.html` из репозитория.
2. Откройте его в любом современном браузере.
3. Введите полученные токены в соответствующие поля в шапке приложения. Они сохранятся в `localStorage` вашего браузера (и будут общими с Reading Test Editor).

## Формат XML

Приложение работает с файлами формата **Formula Builder** и поддерживает обе формы записи.

#### Базовый формат

```xml
<?xml version="1.0" encoding="UTF-8"?>
<formulas name="Название теста">
    <formula name="Теорема Пифагора">a^2 + b^2 = c^2</formula>
    <formula name="Квадратное уравнение">x = \frac{-b \pm \sqrt{b^2-4ac}}{2a}</formula>
</formulas>
```

#### Расширенный формат (с условными обозначениями)

Если у формулы заданы обозначения, редактор автоматически использует расширенную форму:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<formulas name="Физика, тест 2">
    <formula name="Кинетическая энергия">
        <latex>E_k = \frac{m v^2}{2}</latex>
        <symbols>
            <symbol char="E_k" name="кинетическая энергия" />
            <symbol char="m" name="масса тела" />
            <symbol char="v" name="скорость тела" />
        </symbols>
    </formula>
</formulas>
```

> **Примечание:** Название теста хранится в атрибуте `name` корневого элемента `<formulas>`. Тестирующее приложение это поле игнорирует, поэтому файлы остаются полностью совместимыми с Formula Builder.

### Рабочий процесс с Formula Builder

1. Создайте или отредактируйте формулы в редакторе.
2. Сохраните тест (GIST — автоматически, либо скачайте файл и разместите на Яндекс.Диске).
3. Нажмите **«Открыть задание»** — ссылка вида `https://tregubovvn.github.io/ft/index.html?file=<raw_url>` скопируется в буфер обмена.
4. Отправьте ссылку студентам (или оформите её как QR-код средствами самого теста).

## Технологии

- **HTML5 / CSS3**: Семантическая вёрстка, CSS Variables для темизации, Flexbox/Grid для вёрстки.
- **Vanilla JavaScript**: Никаких фреймворков, только нативные API (Fetch, DOMParser, LocalStorage, Clipboard, Blob).
- **KaTeX**: Рендеринг формул и фрагментов в предпросмотре.
- **API**: GitHub REST API v3 (Gists), DeepSeek Chat Completions API.
